เริ่มสมัครได้เมื่อผ่าน Gate 3 จากนั้น Deploy กับการสมัครงานวิ่งขนานกัน เหมือน Simultaneous branch ใน SFC

ประกาศงานต้องการอะไร

ช่องว่างหลักอยู่ที่ Web, ฐานข้อมูล และการ Deploy ส่วนการคิดเป็นระบบและการ Debug มีฐานจากงาน PLC แล้ว

ประกาศระบุฐานเดิมที่ใช้ต่อได้ต้องเพิ่ม
ปริญญาตรีวิศวกรรมศาสตร์หรือวิทยาศาสตร์ สาขาคอมพิวเตอร์หรือที่เกี่ยวข้องต้องตรวจสาขาที่จบโทรถามว่าสาขาของคุณเข้าข่ายหรือไม่
Web application และ Web servicesออกแบบ Function Block และ Control LogicHTTP, REST API, Frontend, Backend
HTML/CSS, VueJS, AngularTSประสบการณ์จาก CALSAVue และ TypeScript ก่อน Angular ไว้ทีหลัง
Node.js, GoLang, PythonStructured Text, SFC, CFCNode.js ก่อน ภาษาอื่นไว้หลังได้งาน
SQL, MySQL, MongoDBยังไม่มีข้อมูลประสบการณ์SQL และการออกแบบตาราง
Docker และ Deploy ขึ้น Productionยังไม่มีข้อมูลประสบการณ์Linux, Docker, Nginx, CI/CD
UAT, SIT, Debug และแก้ Bug หลังใช้งานจริงการไล่ปัญหาเชิงระบบจากงาน PLCเขียน Test Case, อ่าน Log, บันทึก Bug
ทำงานร่วมกับ Software Engineer, Designer, PMการทำงานเป็นโปรเจกต์Git, Pull Request, Issue Tracker

ผู้ประกาศคือ บริษัท อินเทอร์เน็ตประเทศไทย จำกัด (มหาชน) หรือ INET ประจำอำเภอเมืองเชียงใหม่ ประกาศไม่ระบุเงินเดือน AngularTS น่าจะหมายถึง Angular กับ TypeScript ส่วน MongoDB เป็นข้อได้เปรียบ ไม่ใช่สิ่งที่ต้องมีตั้งแต่ต้น

Stack ที่เลือก

เรียนสายเดียวให้ลึกพอทำผลงานจริง ใช้ภาษาเดียวกันได้ทั้ง Frontend และ Backend

ชั้นงานเลือกเรียนเหตุผล
ภาษาTypeScriptมี Type ชัดเจน คล้ายการประกาศตัวแปรใน Structured Text และต่อไป Angular ได้
FrontendVue 3, Viteประกาศระบุ Vue และ 3.5 คือสายเสถียรเมื่อ ส.ค. 2569 เช็กเวอร์ชันล่าสุดก่อนติดตั้ง
BackendNode.js 26, Expressประกาศระบุ Node.js และ 26 เข้าสู่ LTS เมื่อ 28 ต.ค. 2569
ฐานข้อมูลMySQLประกาศระบุชัด และทักษะ SQL ใช้กับฐานข้อมูลเชิงสัมพันธ์อื่นได้
DeployDocker, Nginx, Linux VPSตรงกับงาน Deploy บน Production Server
ทดสอบVitest, Playwrightใช้แสดงความเข้าใจงาน Testing และ UAT

ยังไม่ต้องเรียน Angular, Go, Python และ MongoDB ในรอบนี้ เมื่อผ่าน Gate 4 แล้วค่อยเลือกตามที่บริษัทใช้จริง ถ้าสมัครบริษัทอื่นด้วยให้ดูประกาศเป็นรายบริษัท เพราะ ผลสำรวจระดับโลกปี 2025 มีผู้ใช้ React 46.9% และ Vue 18.4% ซึ่งไม่ได้แทนตลาดเชียงใหม่
