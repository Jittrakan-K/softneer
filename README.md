# PLC to Programmer Roadmap

แผน 26 สัปดาห์สำหรับย้ายสายจากงาน PLC และ Automation สู่ตำแหน่ง Programmer / Developer เริ่มเรียน 9 พ.ย. 2569 เริ่มสมัครงาน 29 มี.ค. 2570 และพร้อมเต็มที่ 10 พ.ค. 2570

## ไฟล์ในโปรเจกต์

| ไฟล์ | เนื้อหา |
| --- | --- |
| `index.html` | หน้าแรก พาไปยังเว็บดีไซน์ใหม่ ใช้กับ GitHub Pages |
| `PLC-to-Programmer-Roadmap-Redesign.html` | เว็บ Roadmap ดีไซน์ใหม่ เลือกเฟสและติ๊กงานได้ |
| `PLC-to-Programmer-Roadmap.html` | เว็บ Roadmap รุ่นแรกแบบผัง SFC |
| `PLC-to-Programmer-Roadmap.pdf` | เอกสาร Roadmap ฉบับเต็ม ขนาด A4 |
| `PLC-to-Programmer-Roadmap.docx` | เอกสาร Roadmap ฉบับ Word |
| `design-source/` | ไฟล์ต้นฉบับของดีไซน์บน Canvas ใช้แก้ต่อ เปิดในเบราว์เซอร์โดยตรงไม่ได้ |

## วิธีเปิดดู

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งโปรแกรมเพิ่ม ฟอนต์โหลดจาก Google Fonts จึงต้องต่ออินเทอร์เน็ต ถ้าออฟไลน์จะใช้ฟอนต์ของเครื่องแทน

ความคืบหน้าที่ติ๊กจะบันทึกไว้ในเบราว์เซอร์ที่เปิด ไม่ถูกส่งขึ้น GitHub และไม่ซิงก์ข้ามเครื่อง

## เปิดเป็นเว็บด้วย GitHub Pages

ไปที่ Settings > Pages ของ Repository เลือก Deploy from a branch แล้วเลือก Branch `main` และโฟลเดอร์ `/ (root)`
